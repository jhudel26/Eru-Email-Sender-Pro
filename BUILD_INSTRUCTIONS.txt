# Eru Email Sender Pro - Build Instructions

## Prerequisites

### Required Software
1. **Python 3.8 or higher**
   - Download from: https://www.python.org/downloads/
   - During installation, check "Add Python to PATH"

2. **PyInstaller**
   - Automatically installed via requirements.txt
   - Or install manually: `pip install pyinstaller`

3. **Inno Setup 6** (for installer creation)
   - Download from: https://jrsoftware.org/isdl.php
   - Install the Unicode version
   - Default installation path is: `C:\Program Files (x86)\Inno Setup 6\`

### Optional Software
- **Microsoft Visual C++ Redistributable** (included in most Windows systems)
- **Git** (if cloning from repository)

## Building the Application

### Quick Build (Automated)
Run the provided batch script:
```batch
build_installer.bat
```

This will:
1. Install all dependencies
2. Build the EXE with PyInstaller
3. Create the installer with Inno Setup

### Manual Build Steps

#### Step 1: Install Dependencies
```batch
pip install -r requirements.txt
```

#### Step 2: Build EXE with PyInstaller
```batch
python -m PyInstaller --clean "Eru Email Sender Pro.spec"
```

This creates:
- `dist/Eru Email Sender Pro.exe` - The main executable
- `build/` - Build artifacts (can be deleted)
- `*.spec` - PyInstaller configuration file

#### Step 3: Create Installer with Inno Setup
```batch
"C:\Program Files (x86)\Inno Setup 6\ISCC.exe" installer_script.iss
```

This creates:
- `installer_output/Eru Email Sender Pro-Setup-2.0.0.exe` - The installer

## Build Options

### PyInstaller Spec File Configuration
The `Eru Email Sender Pro.spec` file contains:
- **Single-file executable**: All files bundled into one EXE
- **No console**: Windowed application (no command prompt)
- **Icon**: EMAIL.ico included
- **Version info**: Uses version_info.txt
- **Hidden imports**: Required libraries for smooth operation

### Inno Setup Script Configuration
The `installer_script.iss` file contains:
- **Professional installer**: Modern wizard interface
- **Desktop shortcut**: Optional desktop icon
- **Start menu entries**: Program group with icons
- **Uninstaller**: Clean removal option

## Troubleshooting

### Common Issues

#### PyInstaller Build Fails
**Problem**: `ModuleNotFoundError` or import errors
**Solution**: 
- Add missing modules to `hiddenimports` in the spec file
- Ensure all dependencies are in requirements.txt

#### Inno Setup Not Found
**Problem**: `ERROR: Inno Setup is not installed`
**Solution**:
- Install Inno Setup from https://jrsoftware.org/isdl.php
- Update the path in build_installer.bat if installed elsewhere

#### EXE Crashes on Startup
**Problem**: Application crashes immediately
**Solution**:
- Test with console mode: Change `console=False` to `console=True` in spec file
- Check error messages in console
- Ensure all dependencies are included

#### Missing Icons
**Problem**: EXE has default icon
**Solution**:
- Ensure EMAIL.ico is in the same directory as main.py
- Check icon path in spec file

#### Application Freezes
**Problem**: UI becomes unresponsive
**Solution**:
- This is usually a threading issue
- Check that worker threads are properly managed
- Ensure COM operations are thread-safe

For smaller EXE size:
- Remove unused dependencies from requirements.txt
- Use UPX compression (already enabled)
- Split into directory mode instead of single-file

## Security Considerations

### Code Signing
For distribution, consider code signing:
- Purchase a code signing certificate
- Sign the EXE with: `signtool sign /f certificate.pfx /p password dist\Eru Email Sender Pro.exe`
- Sign the installer with Inno Setup's signing options

### Anti-Virus False Positives
PyInstaller EXEs may trigger anti-virus:
- Submit to VirusTotal for analysis
- Consider code signing to reduce false positives
- Add to vendor whitelists if necessary
